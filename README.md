# Publish this site with GitHub Pages

1. On GitHub, create a public repository named `tiktok-maximum-quality-encoder` under `binjoharf-rgb`.
2. Upload these four files to the repository root: `index.html`, `privacy.html`, `terms.html`, and this README.
3. Go to **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, then select `main` and `/ (root)`, and save.
4. After GitHub publishes it, use `https://binjoharf-rgb.github.io/tiktok-maximum-quality-encoder/` in TikTok’s **Web/Desktop URL** field.
5. Use these required policy links in TikTok:
   - `https://binjoharf-rgb.github.io/tiktok-maximum-quality-encoder/terms.html`
   - `https://binjoharf-rgb.github.io/tiktok-maximum-quality-encoder/privacy.html`
